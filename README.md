# 소소 커피 주문

9명의 팀원이 하나의 링크에서 커피 메뉴를 제출하고, 제출 후 수정할 수 있는 모바일 웹앱입니다.

## 포함된 흐름

- 팀원 선택
- 음료 선택: 메뉴판의 `COFFEE`, `COLD BREW`, `SIGNATURE`, `ADE`, `NON COFFEE`, `TEA`
- 옵션 선택: 온도, 아메리카노 사이즈, 선택 가능한 원두, 샷 추가/디카페인/오트밀크 변경, 메모
- 제출 완료 및 수정하기
- 전체 제출 현황과 예상 합계

등록 팀원은 `최동일`, `신정은`, `엄승열`, `나영미`, `엄미선`, `이성규`, `최민영`, `주수지`, `김선영`입니다. 이름 변경은 `public/app.js` 상단의 `memberNames` 목록에서 할 수 있습니다.

## 가장 간단히 열기

화면을 먼저 확인할 때는 `소소 앱 미리보기.html` 파일을 더블클릭하세요. 별도의 설치나 주소 입력 없이 브라우저에서 앱 미리보기가 열립니다.

또는 `public/index.html`을 직접 더블클릭해도 같은 미리보기를 볼 수 있습니다. `소소앱 열기.cmd`는 같은 화면을 여는 보조 실행 파일입니다. 이 방식에서는 주문 내용이 현재 브라우저에만 저장됩니다.

## 여러 사람이 함께 사용하기

같은 주문 현황을 여러 사람이 보려면 앱을 온라인 주소에 배포해야 합니다. 개발용 서버를 실행할 수 있는 환경에서는 아래 명령으로 공동 저장 기능을 확인할 수 있습니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 열면 됩니다. 같은 네트워크의 팀원이 접속할 때는 이 앱을 실행하는 컴퓨터의 주소를 사용합니다. 외부에서도 하나의 링크로 접속하려면 이 폴더를 Node.js를 지원하는 웹 호스팅 서비스에 올려 실행하면 제출 데이터가 서버에 함께 저장됩니다.

## 메뉴판 반영 사항

- 아메리카노는 메뉴판에 표시된 `S 1,500원`, 기본 `2,500원`, `L 3,500원` 가격을 반영했습니다.
- `아메리카노`, `카페라떼`에서 `소소 시그니처 블렌드`와 `프리미엄 다크 블렌드`를 선택할 수 있습니다.
- 추가 옵션은 `샷추가 +500원`, `디카페인 변경 +700원`, `오트밀크 변경 +1,000원`으로 반영했습니다.
